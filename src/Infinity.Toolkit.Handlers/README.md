# Infinity.Toolkit.Handlers

Infinity.Toolkit.Handlers is a .NET library that provides a structured approach to handling various tasks and operations in your applications. It includes a set of handlers that can be used to manage different types of requests, responses, and events.

## Installation

To install Infinity.Toolkit.Handlers, add the following package reference to your project file:

```<PackageReference Include="Infinity.Toolkit.Handlers" Version="1.0.0" />```
